# 对话记录 - 2026-03-12

## 一、关键词组合搜索功能（已实现）

- **需求**：多个关键词可组合为一个搜索，而非逐词分别搜索
- **实现**：`KEYWORDS_COMBINE_MODE` / `keywords_combine_mode`
  - 关闭：`A,B,C` → 搜索 3 次（A、B、C 各一次）
  - 开启：`A,B,C` → 搜索 1 次「A B C」
- **入口**：爬取设置、任务管理、命令行 `--keywords-combine`
- **涉及文件**：base_config、core.py、anti_crawl_config、cmd_arg、task.py、dashboard

## 二、Dashboard 状态检测修复（已实现）

- **问题**：多个 API 进程竞争 9001 端口，状态查询被错误进程回答，导致 UI 显示「空闲」而爬虫实际在运行
- **修复**：`get_batch_status` 增加进程存活检测和兜底 pgrep 检测
- **注意**：修复过程中曾误杀爬虫进程，用户已强调「不要中止当前服务」
