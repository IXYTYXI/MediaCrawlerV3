# MediaCrawler 小红书爬虫系统 - 开发文档

## 一、项目概述

基于 [NanmiCoder/MediaCrawler](https://github.com/NanmiCoder/MediaCrawler) 开源项目二次开发，实现小红书作者作品批量爬取、数据过滤、本地 Excel 导出、飞书多维表格写入等功能。

## 四、核心功能模块

### 4.1 批量作者爬取 (`tools/batch_crawler.py`)

**功能：** 从 Excel 读取作者列表，逐个爬取，支持断点续爬和历史数据复用。

**流程：**
```
读取Excel作者列表 → 逐个作者处理：
  ├── 已爬完 → 复用历史数据（过滤后保存到任务目录）
  ├── 部分数据 → 复用已有 + 断点续爬剩余
  └── 无数据 → 全量爬取
→ 汇总任务目录数据 → 导出Excel + 写入飞书
```

**关键设计：**
- **任务ID隔离**：每个任务独立的进度文件和数据目录（`data/xhs/json/{task_id}/`）
- **三种作者状态处理**：completed（复用）、partial（复用+续爬）、none（全量爬）
- **数据去重**：同一 note_id 保留完整度最高的记录（`_note_completeness` 评分）

### 4.2 Excel 读取器 (`tools/excel_reader.py`)

**功能：** 读取作者列表（Sheet1）和结果字段定义（Sheet2）。

**字段映射：**
- Sheet1：名称 | ID | 账号主页链接
- Sheet2：账号名称 | 内容类型 | 标题 | 正文 | 标签 | 链接 | 发布时间 | 图片 | 视频脚本

### 4.3 飞书多维表格 (`tools/feishu_bitable.py`)

**功能：** 创建多维表格、添加字段、批量写入记录、创建筛选视图。

**API 调用链：**
```
获取tenant_access_token → 创建多维表格 → 获取默认表 →
创建字段（按固定顺序）→ 清理默认字段/空记录 → 主字段改名为"序号" →
批量写入记录（每批100条）→ 创建筛选视图
```

**字段顺序：**
序号 → 账号名称 → 内容类型 → 标题 → 正文 → 标签 → 链接 → 发布时间 → 点赞数 → 收藏数 → 评论数 → 互动量 → 热门 → 视频附件 → 视频脚本 → 图片1~N

**特殊处理：**
- 每个作者一个独立数据表（类似Excel的Sheet）
- 主字段不可删除 → 改名为"序号"填入自增编号
- 默认"附件"字段与自定义"视频附件"字段重名 → 改名避免冲突
- 自动创建"🔥热门作品"筛选视图

### 4.4 反爬策略 (`config/anti_crawl_config.json`)

| 策略 | 配置项 | 说明 |
|------|--------|------|
| 随机等待 | 8~23秒，对数正态分布 | 模拟真人浏览节奏 |
| 批次暂停 | 每16~30条暂停30~60秒 | 避免持续高频请求 |
| 动态调整 | 连续成功10次加速，限流时减速 | 自适应频率 |
| 假动作 | 15%概率，滚动/鼠标/模拟输入 | 增加行为真实性 |
| 限流等待 | 递增：4~5分钟 → 8~10分钟 → 15~20分钟 | 300013错误处理 |
| 浏览器指纹 | WebDriver标记移除、Canvas/WebGL伪装 | 防自动化检测 |
| 指数退避 | 最多重试5次，初始2秒 | 错误恢复 |

### 4.5 断点续爬 (`tools/crawl_progress.py`)

**两层进度管理：**
1. **作者级别**：`batch_progress_{task_id}.json` — 记录已完成/失败的作者URL
2. **作品级别**：`data/crawl_progress/` — 记录每个作者已爬取的 note_id（Set集合，O(1) 查找）

### 4.6 Web Dashboard (`dashboard/index.html` + `api/routers/dashboard.py`)

**前端：** Vue 3 + Tailwind CSS（CDN方式，单HTML文件）
**后端：** FastAPI

**6个功能页面：**
1. 爬取设置 — 平台/模式/关键词/作者链接
2. 反爬策略 — 等待时间/假动作/并发控制
3. 批量爬取 — Excel配置/互动量过滤/执行控制
4. 飞书配置 — App ID/Secret
5. 断点续爬 — 启用/保存间隔
6. 日志/文件 — 实时日志/导出文件列表

## 六、遇到的问题与解决方案

### 6.1 浏览器相关

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| CDP模式启动失败，回退到标准模式 | 残留Chrome进程占用端口 | 每个作者爬完后 `pkill -f "Google Chrome Dev"` + 等待2秒 |
| 标准模式显示"Chrome正受自动化控制" | 回退模式未应用反检测参数 | 优先确保CDP模式正常（先杀残留进程） |
| 切换作者时浏览器冲突 | 上一个作者的浏览器未关闭 | `finally` 块中显式关闭 CDP/Playwright + 杀进程 |
| 扫码登录 | Cookie 未保存或CDP失败 | Cookie保存在 `browser_data/` 目录，CDP模式复用 |

### 6.2 反爬限流

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| `code: 300013` 访问频繁 | 请求频率过高 | 递增等待（4~30分钟），成功后重置计数 |
| HTTP 471 + 300013 | 限流通过HTTP状态码触发 | 在HTTP 471分支中检测300013并等待 |
| `success: true` 但实际限流 | 300013的success字段为true | 在JSON code检查中也处理300013 |
| 连续限流 | 单IP请求过频 | 等待时间8~23秒对数正态分布 |

### 6.3 数据质量

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 失败记录保存了不完整数据 | 异常时 `update_xhs_note_basic` 写入基本信息 | 导出时去重，按 `_note_completeness` 评分保留最完整记录 |
| 重复数据 | 多次运行生成多个JSON文件 | 按 note_id 去重，跨文件合并 |
| 图片字段混乱 | 图片数量不固定 | 动态拆列：图片1~图片N，自动检测最大图片数 |
| 发布时间为时间戳 | 小红书返回毫秒级时间戳 | 转换为 `YYYY-MM-DD HH:MM:SS` 格式 |

### 6.4 飞书API

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| `DriveNodePermNotAllow` | folder_token多了URL参数 | 清理 `?fromShareWithMeNew=1` 后缀 |
| `FieldNameDuplicated` | 自定义字段与默认字段同名 | "附件" → "视频附件" |
| 主字段不可删除 | 飞书限制 | 改名为"序号"，填入自增编号 |
| `FieldNameNotFound` | 记录包含表中不存在的字段 | 先扫描所有记录确定字段列表，再创建 |
| 视图筛选条件失败 | `value: []` 格式错误 | `isNotEmpty` 操作符不需要 value 参数 |
| 字段顺序乱 | 用 `sorted()` 按字母排序 | 改为固定顺序列表 |
| 默认空行 | 飞书创建表时自动生成 | 创建后立即删除默认记录 |
| 条件格式不支持整行 | 飞书API限制 | 用筛选视图替代 |

### 6.5 性能与效率

| 问题 | 原因 | 解决方案 |
|------|------|---------|
| 爬取速度慢（18秒/条） | 反爬等待 + 单线程 | 已设计多线程+代理配置项，待实现 |
| 总笔记数未知 | 小红书HTML不提供 | 验证确认无法获取，显示累计数 |
| 断点续爬翻页慢 | 需要翻过所有已爬页面 | 每页30条快速跳过（全部skip） |
| 历史数据复用 | 策略变更后不想重爬 | 自动检测已爬状态，复用符合条件的数据 |

## 七、运行命令

```bash
# 批量爬取（全部作者，跳过飞书）
/opt/anaconda3/envs/uvenv/bin/uv run python -m tools.batch_crawler --skip-feishu --min-interaction 0

# 限制前5个作者
/opt/anaconda3/envs/uvenv/bin/uv run python -m tools.batch_crawler --skip-feishu --limit 5

# 仅导出已有数据为Excel
/opt/anaconda3/envs/uvenv/bin/python -m tools.batch_crawler --export-only --min-interaction 0

# 重置批量进度
/opt/anaconda3/envs/uvenv/bin/uv run python -m tools.batch_crawler --reset-progress

# 启动WebUI
/opt/anaconda3/envs/uvenv/bin/uv run python -m api.main
# 访问: http://localhost:8088/dashboard
```
