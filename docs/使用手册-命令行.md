# MediaCrawler 命令行使用手册

> 本文档面向零基础用户，教你如何用**命令行**运行 MediaCrawler 批量爬取，并拿到符合预期的数据。

---

## 一、使用前准备

### 1.1 进入项目目录

打开终端（Linux/Mac 用终端，Windows 用 PowerShell 或 CMD），执行：

```bash
cd /data/vonjan/program/MediaCrawler
```

（请将路径改为你实际的项目路径）

### 1.2 激活运行环境

项目使用 Conda 环境，环境名为 `uvenv`。运行前需激活：

```bash
conda activate uvenv
```

若你使用 `uv`，可直接执行 `uv run` 开头的命令，无需单独激活。

### 1.3 完成小红书登录（必须）

爬取前必须先完成小红书扫码登录，否则会提示 Session 失效。

- **方式 A**：访问 `https://你的域名/login`，完成扫码
- **方式 B**：在 Dashboard 或控制面板中点击「打开扫码登录」完成扫码

完成一次扫码后，Session 会保存，后续运行无需重复登录。

### 1.4 准备好作者列表 Excel

确保作者列表 Excel 文件已放在项目目录下，例如：

- 文件名：`redbookaccontidandresult.xlsx`
- 路径：`/data/vonjan/program/MediaCrawler/redbookaccontidandresult.xlsx`

Excel 中需包含小红书作者主页链接列（格式如 `https://www.xiaohongshu.com/user/profile/xxx`）。

## 二、基础命令

### 2.1 最简单的运行方式

```bash
conda run -n uvenv python -m tools.batch_crawler
```

或（已激活 uvenv 时）：

```bash
python -m tools.batch_crawler
```

- 会读取 `config/anti_crawl_config.json` 中的配置
- 使用其中的 `excel_path`、`crawl_mode`、`date_start`、`date_end` 等
- 默认会写入飞书（若配置了飞书）

### 2.2 指定 Excel 文件

```bash
python -m tools.batch_crawler --excel redbookaccontidandresult.xlsx
```

或指定完整路径：

```bash
python -m tools.batch_crawler --excel /data/vonjan/program/MediaCrawler/我的作者列表.xlsx
```

### 2.3 跳过飞书写入

若不想写入飞书，只做本地爬取：

```bash
python -m tools.batch_crawler --skip-feishu
```

### 2.4 只爬前 N 个作者（测试用）

```bash
python -m tools.batch_crawler --limit 5
```

表示只爬 Excel 中的前 5 个作者，便于快速测试。

## 三、常用参数速查

| 参数 | 说明 | 示例 |
|------|------|------|
| `--excel 文件路径` | 指定作者列表 Excel | `--excel my_list.xlsx` |
| `--skip-feishu` | 跳过飞书写入 | 直接加即可 |
| `--limit N` | 只爬前 N 个作者，0=全部 | `--limit 10` |
| `--max-notes N` | 每作者最多爬 N 条 | `--max-notes 2000` |
| `--min-interaction N` | 互动量过滤，低于 N 不保存，0=不过滤 | `--min-interaction 50` |
| `--enable-comments` | 爬取评论（会显著变慢） | 直接加即可 |
| `--no-resume` | 不使用断点续爬，从头开始 | 直接加即可 |
| `--force-recrawl` | 重置进度 + 全部重爬 | 直接加即可 |
| `--export-only` | 只导出已有数据，不爬取 | 直接加即可 |
| `--export-format 格式` | 导出格式 | `excel` / `json` / `csv` |
| `--export-dir 目录` | 导出保存目录 | `--export-dir data/export` |
| `--reset-progress` | 仅重置进度，不爬取 | 直接加即可 |

## 四、爬取模式（配置文件）

爬取模式（全量/日期范围/增量）由 `config/anti_crawl_config.json` 中的 `batch_crawl` 决定。用文本编辑器打开：

```bash
nano config/anti_crawl_config.json
```

或：

```bash
vim config/anti_crawl_config.json
```

找到 `batch_crawl` 段，修改：

| 配置项 | 说明 | 可选值 |
|--------|------|--------|
| `crawl_mode` | 爬取模式 | `full` / `date_range` / `incremental` |
| `date_start` | 开始日期（日期范围模式） | 如 `2025-01-01` |
| `date_end` | 结束日期（日期范围模式） | 如 `2026-02-26` |
| `excel_path` | Excel 路径 | 如 `redbookaccontidandresult.xlsx` |
| `task_id` | 任务 ID，不同任务数据独立 | 如 `task_20260226` |

**模式说明：**

- `full`：全量爬取，每个作者从头到尾爬
- `date_range`：只爬 `date_start`～`date_end` 区间的笔记
- `incremental`：对已完成的作者，只爬上次之后的新内容

保存配置文件后，再用命令行运行即可。

## 五、典型使用场景

### 5.1 第一次全量爬取

1. 确认 `config/anti_crawl_config.json` 中：
   - `crawl_mode`: `"full"`
   - `excel_path`: 你的 Excel 文件名
   - `task_id`: 如 `task_20260226`
2. 执行：

```bash
conda run -n uvenv python -m tools.batch_crawler --skip-feishu --min-interaction 0 --max-notes 3000
```

### 5.2 只导出已有数据（不爬取）

```bash
python -m tools.batch_crawler --export-only --export-format excel --min-interaction 0
```

导出文件在 `data/export`（或配置的 `export_dir`）下。

### 5.3 强制全部重爬

```bash
python -m tools.batch_crawler --force-recrawl
```

会重置进度，禁用历史复用，从头爬取每个作者。

### 5.4 只补图（不爬新数据）

对已有 JSON 数据补下载缺失图片：

```bash
python -m tools.batch_crawler --patch-only --patch-limit 50
```

`--patch-limit 50` 表示本次最多补 50 条笔记的图片，0 表示不限制。

### 5.5 重置进度后重新爬

仅清空进度，不立即爬取：

```bash
python -m tools.batch_crawler --reset-progress
```

## 六、在后台运行（长时间爬取）

### 6.1 使用 nohup

```bash
nohup python -m tools.batch_crawler --skip-feishu > crawler.log 2>&1 &
```

- 日志输出到 `crawler.log`
- 终端关闭后进程继续运行
- 用 `tail -f crawler.log` 可实时查看日志

### 6.2 使用 tmux

```bash
tmux new-session -d -s crawler 'conda run -n uvenv python -m tools.batch_crawler --skip-feishu'
```

- 在 tmux 会话 `crawler` 中后台运行
- 查看：`tmux attach -t crawler`
- 退出但不结束：`Ctrl+B` 然后按 `D`

### 7.1 运行中

- 终端有持续输出，包含作者名、笔记数、进度等
- 无频繁「Session 失效」「验证码」等错误

- 导出文件在 `data/export`（或配置的目录）
- 可用 Excel 打开，检查列是否完整、互动量是否过滤正确

## 八、常见问题

### Q1：提示「Session 失效」？

- 先完成小红书扫码登录（见 1.3）
- 登录一次后，Session 会保存，后续可继续使用

### Q2：找不到 Excel 文件？

- 用 `ls` 确认文件是否存在
- 路径可为相对路径（相对于项目根目录）或绝对路径

### Q3：想改爬取模式，命令行有参数吗？

- 爬取模式在配置文件中修改（见第四节）
- 命令行无 `--crawl-mode`，需改 `config/anti_crawl_config.json`

### Q4：如何停止正在运行的爬虫？

- 在运行爬虫的终端按 `Ctrl+C`
- 爬虫会保存当前进度后退出（支持优雅退出）

### Q5：conda 和 uv 有什么区别？

- 本项目部署使用 Conda，推荐 `conda run -n uvenv python -m tools.batch_crawler`
- 若本地用 uv，可写 `uv run python -m tools.batch_crawler`
