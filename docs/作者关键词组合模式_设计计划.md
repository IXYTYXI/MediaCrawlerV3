# 作者 × 关键词 组合搜索模式 — 设计计划

> 创建日期：2026-03-12  
> 状态：**基础功能已实现** (2026-03-13)  
> 用途：开发参考

---

## 一、需求背景

当前已有三种独立模式：
1. **关键词搜索**：指定关键词，平台搜索
2. **作者主页**：指定作者，爬取其全部笔记
3. **作者×关键词**（待实现）：指定作者 + 指定关键词，只取这些作者且与关键词相关的笔记

---

## 二、关键词逻辑

### 2.1 运算符约定

| 符号 | 含义 | 示例 |
|------|------|------|
| `\|` | OR，命中任一即可 | `小学\|数学` → 含「小学」或「数学」即过 |
| `&` | AND，必须全部命中 | `小学&数学` → 必须同时含「小学」和「数学」 |
| 空格 | 组合词，作为整体匹配 | `小学 数学` → 需出现「小学 数学」这一串 |

### 2.2 混合示例

- `小学 数学|网课`：含「小学 数学」**或** 含「网课」
- `小学&数学&网课`：必须同时含「小学」「数学」「网课」
- `小学 数学&提前学`：含「小学 数学」**且** 含「提前学」

### 2.2 配置层级

- **按任务配置**：每个任务一套关键词逻辑（OR/AND、组合词规则、过滤范围等）

---

## 三、过滤范围

| 字段 | 说明 | 默认 | 可配置 |
|------|------|------|--------|
| 标题 | `title` | ✅ | - |
| 正文 | `desc` / `content` | ✅ | - |
| 话题标签 | `tag_list` | ✅ | - |
| 评论内容 | 一级/二级评论 | ❌ | ✅ 可选 |
| 作者简介 | 作者 `desc` | ❌ | ✅ 可选 |

- 默认参与过滤：标题 + 正文 + 标签
- 可选扩展：评论、作者简介（任务级开关）

---

## 四、n 作者 × n 关键词 笛卡尔积模式

### 4.1 流程

```
作者列表 [A, B, C] × 关键词列表 [K1, K2]
  → (A,K1), (A,K2), (B,K1), (B,K2), (C,K1), (C,K2)
```

每个 (作者, 关键词) 组合：
1. 爬取该作者的笔记（复用现有创作者模式）
2. 用该关键词及 OR/AND/组合词 规则做本地过滤
3. 保存结果

### 4.2 结果合并策略

- **合并多作者模式**：同一笔记可能被多个 (作者, 关键词) 命中
- 以 `note_id` 为唯一键，**只保留一条记录**
- 记录中汇总来源：`source_authors`（如 `["A","B"]`）、`source_keywords`（如 `["K1","K2"]`）

### 4.3 规模与优先级

- 支持大量组合（如 20×10 = 200）
- 支持**执行优先级/顺序**：可指定先跑某些作者或某些关键词
- 建议：单次任务组合数上限（如 100）、单作者最大笔记数、断点续爬

## 五、与现有模式的关系

| 模式 | 输入 | 行为 |
|------|------|------|
| search | 关键词 | 平台关键词搜索 |
| search_top | 关键词 | 平台高赞搜索 |
| creator | 作者 | 爬取作者全部笔记 |
| **creator_keyword**（新） | 作者 + 关键词 | 爬作者 → 本地按关键词过滤，支持 n×n |

## 六、实现要点（开发时参考）

### 6.1 新增爬取类型

- `crawler_type`: `creator_keyword` 或 `creator+search`

### 6.2 任务/配置字段示例

```
creator_urls: [...]      # 作者列表
keywords: "..."         # 关键词，支持 | & 空格组合词
keywords_logic: "or"|"and"  # 顶层 OR/AND（若未在关键词串中显式写 | &）
filter_scope: {
  title: true,
  desc: true,
  tags: true,
  comments: false,      # 可选
  author_desc: false   # 可选
}
cartesian_mode: true    # 是否 n×n 笛卡尔积
max_combinations: 100  # 组合数上限（可选）
```

### 6.3 关键词解析

- 解析 `|`、`&`、空格组合词
- 按运算符拆分为多个「匹配单元」
- 每个单元可以是单词或组合词

### 6.4 本地过滤逻辑

- 对笔记的 title、desc、tag_list 等拼接为待检文本
- 若开启，加入评论、作者简介
- 按 OR/AND/组合词规则判定是否匹配

### 6.5 数据落库

- 合并多作者时：`note_id` 唯一，`source_authors`、`source_keywords` 记录来源
- 飞书等导出需兼容新字段

1. **关键词解析器** — `tools/keyword_filter.py`，支持 `|`(OR)、`&`(AND)、空格(组合词)
2. **配置层** — `base_config.py` 新增 `CREATOR_KEYWORD_FILTER_KEYWORDS`、`CREATOR_KEYWORD_FILTER_SCOPE`
3. **命令行参数** — `cmd_arg/arg.py` 新增 `creator_keyword` 枚举值、`--filter_keywords`、`--filter_scope`
4. **核心爬取逻辑** — `core.py` 新增 `get_creators_and_notes_by_keyword()` 方法，复用 creator 模式 + 本地过滤
5. **任务系统** — `task.py` TaskConfig 新增 `filter_keywords`、`filter_scope`，`_build_cmd` 适配
6. **Dashboard UI** — 爬取类型下拉新增「作者×关键词」，任务表单新增过滤关键词和范围设置
