# MediaCrawler Dashboard 使用手册

> Dashboard 用于：登录管理、爬取设置、批量爬取、飞书写入、查看日志与数据文件。
> 访问地址：`https://你的域名/dashboard`（例如 `https://crawler.ooioo.us.ci/dashboard`）

---

## 一、首次使用前的准备

### 1.1 登录 Dashboard

打开 Dashboard 后，会看到登录界面。输入**管理密码**（与部署时设置的 `MC_DASHBOARD_PWD` 一致）。

- 密码正确后进入主界面
- 之后刷新页面会自动保持登录状态

### 1.2 完成小红书登录（必须）

在开始爬取前，必须先完成小红书的扫码登录。

1. 在左侧点击「**登录管理**」
2. 点击「**打开扫码登录**」按钮
3. 新窗口会打开登录页，用小红书 App 扫描二维码
4. 扫码成功后，窗口会提示「登录成功」，可关闭
5. 返回 Dashboard，点击「**刷新状态**」，应看到「Session 状态：有效」和「爬虫状态」等

> 重要：若未完成扫码就启动爬取，会出现 Session 失效错误，无法爬取。

## 二、批量爬取配置

点击左侧「**批量爬取**」，配置以下内容。

### 2.1 基础配置

| 配置项 | 说明 | 推荐值 |
|-------|------|--------|
| **Excel 路径** | 作者列表 Excel 文件路径 | 如 `redbookaccontidandresult.xlsx` |
| **爬取模式** | 全量/日期范围/增量更新 | 首次用「全量爬取」 |
| **每作者最多作品** | 每个作者最多爬多少条 | 2000~3000 |
| **互动量阈值** | 低于此值不保存 | 0=不过滤，50=过滤低互动 |
| **导出格式** | 导出文件格式 | Excel / JSON / CSV |
| **导出目录** | 导出保存位置 | `data/export` |
| **作者间等待 (秒)** | 每作者间隔 | 10~30 |

### 2.2 爬取模式说明

- **全量爬取**：每个作者从头到尾爬，数据最完整，适合第一次
- **日期范围**：只爬指定日期区间，需填写「开始日期」「结束日期」
- **增量更新**：对已完成的作者，只爬上次之后的新内容，适合每周补新

### 2.3 作者列表

1. 点击「**刷新**」加载 Excel 中的作者
2. 确认列表中的作者数量、链接是否正确
3. 若为空，检查 Excel 路径是否正确、文件是否存在

### 2.4 执行控制

| 选项 | 说明 |
|------|------|
| **限制作者数** | 填 0 表示爬全部，填数字则只爬前 N 个（用于测试） |
| **互动量过滤** | 与上面「互动量阈值」一致 |
| **爬取评论** | 勾选则爬评论，会显著增加时间 |
| **每次全量** | 勾选后本次会重置进度、全部重爬，适合需要完整数据时 |

### 2.5 保存配置

修改配置后，点击右上角「**保存配置**」按钮，确保配置被写入。

## 三、启动批量爬取

### 3.1 启动

1. 确认已保存配置
2. 点击绿色「**开始批量爬取**」按钮
3. 按钮变为「运行中...」，顶部状态栏显示「爬取中」

### 3.2 查看日志

1. 点击左侧「**日志/文件**」
2. 「批量爬取日志」区域会显示实时日志
3. 若无日志，点击「刷新」，或等待几秒自动刷新
4. 日志会每 5 秒自动更新

### 3.3 查看数据文件

在同一页面下方「**数据文件**」区域：

1. 点击「刷新」加载文件列表
2. 列表中会显示 JSON 文件（按作者）及笔记条数
3. 点击「**查看**」可预览文件内容，支持分页

### 3.4 停止爬取

点击红色「**停止**」按钮。爬虫会先保存当前进度再退出。

---

## 四、导出数据

### 4.1 导出为 Excel

1. 爬取完成后，点击「**导出 Excel**」按钮
2. 系统会按互动量过滤后导出
3. 导出文件在「数据文件」中可见，或到 `data/export` 目录查找

### 4.2 重置进度

若希望下次「从头再爬」：

- 点击「**重置进度**」，确认后可清空完成状态
- 或勾选「每次全量」后再次启动（会自动重置）

---

## 五、其他功能

### 5.1 登录管理

- **验证 Session**：检查当前登录是否有效
- **刷新状态**：更新浏览器数据、爬虫状态等
- **手动更新 Cookie**：若扫码不可用，可粘贴 `web_session` 值

### 5.2 快捷操作

- **开始爬取**：跳转到批量爬取并直接启动
- **导出数据**：触发导出
- **终端日志**：打开终端日志页面
- **控制面板**：跳转到控制面板

### 5.3 飞书配置

若需将数据自动写入飞书多维表格：

1. 在「飞书配置」中填写 App ID、App Secret、文件夹 Token
2. 开启「启用飞书写入」
3. 爬取完成后会自动创建/更新飞书表格

## 六、常见问题

### Q1：点击「开始批量爬取」无反应？

- 检查是否已保存配置
- 检查是否已完成小红书扫码登录
- 查看「日志/文件」中是否有报错

### Q2：日志区域一直显示「暂无日志」？

- 点击「刷新」按钮
- 若从控制面板或命令行启动的爬虫，日志也会显示在这里
- 等待几秒，系统会每 5 秒自动刷新

### Q3：数据文件列表为空？

- 确认爬取已运行并产生数据
- 检查任务 ID 与 Excel 路径是否与爬取时一致
- 点击「刷新」重新加载

### Q4：爬虫状态显示「未运行」但实际在爬？

- 点击「刷新状态」
- 若从命令行启动，状态也会正确显示（已支持外部爬虫检测）

---

## 七、预期结果

- **启动成功**：顶部显示「爬取中」，日志有输出
- **爬取完成**：状态变为「空闲」或「已完成」，数据文件列表有内容
- **导出成功**：可在数据文件中看到 Excel，或到 `data/export` 查看

按以上步骤操作，即可完成从登录、配置、爬取到查看结果的全流程。
